
# AI-Based Personal Finance and Savings Advisor

## Project Overview

An AI-powered web application designed to help users
track personal income and expenses, analyze spending
patterns, establish savings goals, and receive
personalized financial guidance.

## Problem Statement

Many people struggle to manage expenses, create realistic
budgets, and achieve their savings goals.

This project combines financial calculations, data
visualization, and generative AI to support better
personal financial management.

## Technology Stack

- Python
- Streamlit
- Pandas
- Plotly
- SQLite
- Groq API
- Git and GitHub

## Planned Features

- Income and expense tracking
- Financial dashboard
- Spending analysis
- Savings goal planner
- AI-powered financial insights
- Monthly reports

## Run Locally

Install the dependencies:

    pip install -r requirements.txt

Start the application:

    streamlit run app.py
